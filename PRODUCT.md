# Product

## Register

product

## Users

Mac users who want fast, keyboard-driven control over application windows, clipboard history, text expansion, and focused screen-region sharing without leaving their current workflow.

## Product Purpose

WindowSnap is a lightweight native macOS menu-bar utility that makes frequent desktop tasks immediate and predictable. Success means users can invoke an action, understand any required system permission, and return to work with minimal interruption.

## Brand Personality

Native, efficient, trustworthy. WindowSnap should feel calm and familiar, with the clarity and restraint of a well-made macOS utility.

## Anti-references

Avoid interfaces that imitate a web dashboard inside a native app, decorative visual effects, unfamiliar replacements for standard macOS controls, crowded menus, and permission flows that hide system state or leave users without a recovery action.

## Design Principles

- Prefer familiar macOS behavior and system-provided visual language.
- Keep common actions immediate and advanced functionality progressively disclosed.
- Make system state and recovery steps explicit, especially for permissions.
- Preserve user trust through local processing, clear privacy language, and predictable behavior.
- Treat keyboard, pointer, and accessibility use as equal first-class workflows.

## Accessibility & Inclusion

Use native AppKit semantics, visible keyboard focus, descriptive accessibility labels, sufficient contrast in light and dark appearances, template-aware menu-bar imagery, and reduced-motion-safe interactions. Support macOS 13 and later without relying on newer symbols unless a compatible fallback exists.
